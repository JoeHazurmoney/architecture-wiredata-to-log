# wd2l 0.3.0rc5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release 0.3.0rc5: a signed amd64 + arm64 container image, container mode that works
under SELinux, the five items deferred from rc4, and a `--max-stratum` setting.

**Architecture:** The image is built natively on GitHub's amd64 and arm64 runners, checked per
architecture, pushed as one OCI index, signed (index and each platform image), and shipped
offline as one OCI tar per platform. Container mode stops relabelling `/var/lib/wd2l` with `:z`;
a CIL module in the base package labels it `container_file_t` instead, and the receiver's module
lets containers read (never write) the capture archive. The small items are host-side fixes.

**Tech Stack:** Python 3.9+ standard library (wd2l), bash, systemd and Quadlet units, RPM spec,
SELinux CIL, GitHub Actions, Podman 4.9 / 5.x, cosign 3 (pinned `hi/cosign`), skopeo, oras.

**Spec:** the approved plan, `C:\Users\taylo\.claude\plans\i-want-to-deploy-tender-melody.md`
(Part B), plus the spike results below. The spike evidence is on the throwaway branch
`spike/multiarch` (`.github/workflows/spike.yml`, runs 38176759764, 38183229150, 38183490370)
and in `/home/taylorb/s7*.sh`, `~/s6/` on the Pi.

## Review Focus

1. **Podman installed after the RPM:** `/var/lib/wd2l` keeps `var_lib_t` until `restorecon -RF`
   runs, and the container can't write its state. Expect containers.md to say so and the check
   to show it (Task 4 pins the doc line).
2. **A host upgraded from rc4 where `:z` already relabelled `pcap/`:** the receiver's `%post`
   must reset it (`restorecon -RF`, not `-R`). Task 4 pins the spec line.
3. **One architecture's build fails:** no release may be published with one platform. Task 7's
   `image_index.py` refuses an index without both platforms; `publish` needs both.
4. **The ARP watcher on a veth or VLAN NIC:** link events name `IFACE@peer`; a filter that only
   matches `IFACE:` would stop restoring the ARP entry on the single-box setup. Task 1 tests it.
5. **A future cosign drops the deprecated older-format flags:** the publish step must fail
   loudly, not ship without the Podman-readable signature. Task 10's `verify-published` and
   `import-check` check that signature, so a missing one fails the release.

```python
#!/usr/bin/env python3
"""Checks the image index publish.yml pushed: an OCI index whose digest is the one pushed,
holding exactly linux/amd64 and linux/arm64, each the image that arch's build tested (its config
digest is the tested image ID). Writes digest_amd64= and digest_arm64= for the later steps.

    image_index.py --index index.json --digest sha256:... --manifest amd64=m.json
        --manifest arm64=m.json --build-info amd64=b.json --build-info arm64=b.json
        [--github-output FILE]"""

import argparse
import hashlib
import json
import sys
from typing import Dict, List, Optional, Sequence, Tuple

ARCHES = ("amd64", "arm64")
OCI_INDEX = "application/vnd.oci.image.index.v1+json"


def _sha(b: bytes) -> str:
    return "sha256:" + hashlib.sha256(b).hexdigest()


def check(index: bytes, digest: str, manifests: Dict[str, bytes],
          image_ids: Dict[str, str]) -> Tuple[Dict[str, str], List[str]]:
    probs: List[str] = []
    if _sha(index) != digest:
        probs.append("the index fetched (%s) is not the digest pushed (%s)" % (_sha(index), digest))
    doc = json.loads(index)
    if doc.get("mediaType") != OCI_INDEX:
        probs.append("not an OCI image index: %s" % doc.get("mediaType"))
    found = {(m.get("platform") or {}).get("architecture"): m["digest"]
             for m in doc.get("manifests", []) if (m.get("platform") or {}).get("os") == "linux"}
    if set(found) != set(ARCHES):
        probs.append("the index holds %s, not exactly linux/amd64 and linux/arm64"
                     % ", ".join("linux/%s" % a for a in sorted(found)))
    out: Dict[str, str] = {}
    for arch in ARCHES:
        if arch not in found:
            probs.append("no linux/%s image in the index" % arch)
            continue
        m = manifests.get(arch, b"")
        if _sha(m) != found[arch]:
            probs.append("%s: the manifest fetched is not %s" % (arch, found[arch]))
            continue
        cfg = json.loads(m).get("config", {}).get("digest")
        if cfg != "sha256:" + image_ids.get(arch, ""):
            probs.append("%s: the image pushed (config %s) is not the one tested (%s)"
                         % (arch, cfg, image_ids.get(arch)))
        out[arch] = found[arch]
    return out, probs


def _pairs(items: Sequence[str]) -> Dict[str, str]:
    return dict(x.split("=", 1) for x in items)


def main(argv: Optional[Sequence[str]] = None) -> int:
    p = argparse.ArgumentParser(description="Check the pushed image index.")
    p.add_argument("--index", required=True)
    p.add_argument("--digest", required=True)
    p.add_argument("--manifest", action="append", default=[], metavar="ARCH=FILE")
    p.add_argument("--build-info", action="append", default=[], metavar="ARCH=FILE")
    p.add_argument("--github-output")
    a = p.parse_args(argv)
    with open(a.index, "rb") as f:
        index = f.read()
    manifests = {}
    for arch, path in _pairs(a.manifest).items():
        with open(path, "rb") as f:
            manifests[arch] = f.read()
    ids = {}
    for arch, path in _pairs(a.build_info).items():
        with open(path) as f:
            ids[arch] = json.load(f)["image_id"]
    got, probs = check(index, a.digest, manifests, ids)
    for x in probs:
        print("image-index: " + x, file=sys.stderr)
    if probs:
        return 1
    lines = ["digest_%s=%s" % (arch, d) for arch, d in sorted(got.items())]
    print("\n".join(lines))
    if a.github_output:
        with open(a.github_output, "a") as f:
            f.write("\n".join(lines) + "\n")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

def runners(body: str):
    """The runner labels a job can use: its runs-on, or each matrix entry's runner."""
    label = re.search(r"^\s+runs-on:\s*(.+?)\s*$", body, re.M).group(1)
    if "matrix.runner" in label:
        return re.findall(r"runner:\s*([\w.-]+)", body)
    return [label]
